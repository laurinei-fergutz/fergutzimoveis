# Fergutz Imóveis

Landing page institucional da **Fergutz Imóveis** — imobiliária em Mangueirinha - PR, com atuação em compra, venda e aluguel de imóveis, além de consórcio imobiliário.

## Sobre o projeto

Site em página única (single file), construído com:

- **HTML5**
- **Tailwind CSS** (via CDN)
- **JavaScript** puro (menu mobile, revelação de seções ao rolar a página, ano dinâmico no rodapé)

Não há build, framework ou dependências de instalação — é um único arquivo `index.html` pronto para rodar em qualquer navegador ou publicar em qualquer serviço de hospedagem estática.

## Seções

- Cabeçalho fixo com menu (Sobre, Serviços, Consórcio, Catálogo, Contato)
- Hero com chamada principal para WhatsApp
- Sobre a imobiliária
- Serviços (compra, venda, aluguel, consultoria)
- Consórcio de imóveis
- Catálogo de imóveis nas redes sociais (Instagram e Facebook)
- Contato e localização (endereço, e-mail, WhatsApp e mapa incorporado)
- Botão flutuante de WhatsApp
- Rodapé com redes sociais

## Como visualizar localmente

Basta abrir o arquivo `index.html` diretamente no navegador — não é necessário servidor.

Se preferir servir localmente:

```bash
python3 -m http.server 8000
```

E acesse `http://localhost:8000`.

## Publicar com GitHub Pages

1. Vá em **Settings → Pages** no repositório.
2. Em **Source**, selecione a branch `main` e a pasta `/root`.
3. Salve — o GitHub Pages publica automaticamente em alguns minutos, em um endereço como `https://laurinei-fergutz.github.io/fergutzimoveis/`.
